# Ai-detectors — 수능 시험장 AI 부정행위 전파 탐지 (1단계: 시뮬레이션)

교육부 제안용 프로토타입. 시험장에서 **몰래 숨긴 송신 기기**(스마트폰, 무선 이어폰, 스마트워치, 스마트안경, 소형 송신기)를
센서의 전파 세기 관측만으로 찾아 3D 교실 지도에 좌석 단위 확률로 보여주는 방식을 가상 데이터로 검증한다.

## 실행

```bash
cd sim && python3 -m http.server 8765   # 브라우저에서 http://localhost:8765
node sim/test.mjs                       # 정확도/오탐 통계 (센서 수·캘리브레이션별)
```
Three.js는 `sim/vendor`에 포함되어 있어 인터넷 없이 동작한다.

## 구성

| 파일 | 역할 |
|---|---|
| `sim/engine.js` | 신호 모델, 위치 추정(3D 최대우도 + 좌석별 사후확률), 활동 패턴 분석, 위험도 |
| `sim/main.js`, `index.html` | 3D 시각화, 열지도, 타임라인, 경보 로그 |
| `sim/test.mjs` | 몬테카를로 검증 |

## 무엇을 하고 / 못 하는가

- 관측: 신호 세기(RSSI)와 송신 시점만. **파일 내용·정확한 전송량·송수신 방향은 알 수 없다.**
  대신 *송신 활동량(밀도)* 과 *질의→응답 패턴*(짧은 송신 폭발 뒤 후속 트래픽)으로 AI 사용을 추정한다.
- 위치: 좌석 단위 **확률**(후보 좌석 상위 3개)과 오차 범위. 확정 증거가 아니라 감독관이 확인할 단서다.
- 감독관석 구역은 제외 처리. 전원이 꺼졌거나 수신 전용인 기기는 탐지 불가.
- 재밍(전파 차단)은 구현하지 않는다(전파법 위반).

## 센서 구성 3종 (UI에서 선택)

- **고정 센서 설치형**: 천장/벽 센서 4~12개, 전 대역(블루투스/Wi-Fi/셀룰러/소출력무선) 탐지
- **감독관 폰 6대**: 교실 3 + 복도 3(벽 너머), 순찰/제자리 선택, 폰 위치 오차 조절. **블루투스/Wi-Fi만 탐지(셀룰러 불가)**
- **혼합**: 고정 센서 + 감독관 폰

감독관 폰은 시험 중 외부 통신을 하지 않는다는 전제(앱에 인터넷 권한 없음, 단말 저장 후 회수)로 설계했다. 자세한 내용은 [`docs/제안서_요약.md`](docs/제안서_요약.md).

## 시뮬레이션 검증 결과

`node sim/test.mjs` (30회 평균, 약 5분 소요) / `node sim/test.mjs --quick` (CI용, 1초).
구성별·기기 유형별 탐지율, 수평오차, 오탐 표는 제안서 요약 4절 참고. 핵심:

- 폰만으로는 **셀룰러 기기를 탐지하지 못한다**(탐지율 0%).
- BLE/Wi-Fi 기기는 감독관 순찰 시 수평오차 약 0.7 m, 제자리 약 1.4 m.
- 고정 센서 8개는 캘리브레이션 없이 약 1.0 m, 있으면 약 0.4~0.5 m.
- 폰 위치 오차가 ±1.5 m면 폰 구성의 정확도가 고정 센서보다 나빠진다.
- 정상 시험 오탐 0/30. 수치는 가정 기반 시뮬레이션이며 실측 성능이 아니다.

## 배포

- `node build.mjs` (esbuild 필요): 파일 하나로 열리는 `dist/index.html` 생성.
